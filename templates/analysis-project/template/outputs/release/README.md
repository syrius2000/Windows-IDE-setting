# Release Outputs Directory

このディレクトリ（`outputs/release/`）は、**人手レビューを経て承認された公開可能成果物（集約テーブル、グラフ、最終報告書）**を格納する領域です。

## 📋 開示統制手順
1. 本ディレクトリにファイルを配置する場合、患者個票や直接識別子（ID、氏名、生年月日等）が含まれていないことを確認してください。
2. 小セル（頻度 < 5 等）の再識別リスクを評価し、必要に応じてマスキング・集約を行ってください。
3. 同一ディレクトリ内の `release-manifest.yml` を編集し、レビュー実施日、確認者、チェック項目を記録してコミットしてください。
