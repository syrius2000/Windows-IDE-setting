# Private Outputs Directory

このディレクトリ（`outputs/private/`）は、**解析の中間テーブル、患者単位の個票listing、実行ログ、および非公開データ**を一時的に出力する領域です。

## ⚠️ 取扱規則（重要）
1. **Git追跡完全除外**: 本ディレクトリ内のファイルは `.gitignore` によりGit管理から自動的に除外されます。
2. **クラウドAI送信禁止**: 個票データや中間集計をクラウドAI（Cursorチャット/プロンプト等）に直接入力しないでください。
3. **成果物の外部公開**: 報告書や外部発表に使用する集約結果・図表は、直接識別子の除去および小セル抑制の人手確認を行った上で `outputs/release/` に配置し、`release-manifest.yml` を記録してください。
